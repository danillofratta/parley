# Git and documentation

- Conventional Commits: `feat(scope):`, `fix(scope):`, `test(scope):`,
  `docs:`, `chore:`, `refactor(scope):`. Scope = service or area.
- One idea per commit; one story (OC-xxx) per PR; PR body has `Closes #N`.
- Code, comments, docs and ADRs in English.
- A new architecture decision needs an ADR (skill `write-adr`).
- Keep `docs/requirements.md` and `docs/domain/` in sync with the code.
